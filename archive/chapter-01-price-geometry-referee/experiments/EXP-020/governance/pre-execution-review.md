## Executive Summary

EXP-020 is aligned with the active Phase 004 AVWAP signal-exploration design:
it is a substrate-readiness experiment for `CF-AVWAP-001/HYP-001`, not a market
edge test, not a frozen-suite candidate screen, and not a cTrader strategy-host
run. The scope and analysis plan define one falsifiable readiness question, use
the registered MA(20,50) AVWAP branch, exclude chart-type views, and keep the
global holdout sealed.

During critical review, the implementation initially lacked independent
post-generation checks for the two key substrate claims: viable-pivot anchor
selection and arm/trigger causality. That was revised before approval. The
experiment code now records explicit invariant rows for anchor selection,
event timestamp/index consistency, arming condition, trigger condition,
AVWAP/band value consistency, and re-arm sequencing.
