## Deviations (all raised pre-implementation, operator-resolved 2026-07-08)

- **D1** sentinel ADX median window = trailing 2016 closed 1h bars.
- **D2** TEST family = E0×4 holds + exit* single stat (design §8 amended in place).
- **D3** E2 ≡ E6 for this vehicle (identical predicate; both implemented, distinct labels). **RESOLVED 2026-07-08 (operator, QA Issue 4, option b):** design §3 amended in place — E6 = DI-gated opposite breakout (opposite X-break AND HTF-DI gate admits opposite direction). Predicate split in `HtfDiBreakoutModel.cs` (E2 raw channel breach; E6 adds `snap.PlusDi<MinusDi` long / mirror short). E6 now strictly rarer, no duplication. Branch unexercised by T1 (E0/ref/sent only); QA must re-trace split branch before any T2 run using e6.
- **D4** reference arm = state-emission run + analysis-side seed-2001 sampling (EXP-019 D1 precedent).
- **D5** battery preserves candidate entry timestamps exactly under E0; approximate under direction-dependent exits (analyst discloses cadence deltas).
